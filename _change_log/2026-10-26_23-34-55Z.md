- Plugin: `obsidian-plugin/` package, manifest at repo root, real-Obsidian headless Playwright E2E.
- Mindmap note (`organic-mindmap: 1`): list = tree, block id = node id, `%%` layout block with parent offsets. Opens as a map; add/rename/move/delete (Undo) written to the note; linked-note renames update it.
